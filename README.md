# Suchita Padhye — Portfolio

A responsive React + Vite portfolio website with a light, clean visual style, subtle CSS motion, an uploaded profile photo, skill groupings, expandable project cards, research, and contact links.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. In the terminal run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Build for deployment

```bash
npm run build
npm run preview
```

The production site is generated in `dist/`.

## Personalize later

Open `src/App.jsx` and update the `profile` object near the top:
- `linkedin`: your LinkedIn profile URL
- `resume`: a public resume URL (if you want a Download Resume link)

Add project repository/demo links when available. Project content is in the `projects` array. Replace `public/profile.jpeg` if you want to use a different portrait.
